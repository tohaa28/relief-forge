## 0.1.0-alpha.1 — независимый Rust/WASM прототип (22.10.2026)
- **Задача:** инструмент «Лечение векторов», похожий по функциям на ArtCAM, а не копия недоступного исполняемого файла.
- **Реализация:** Rust-ядро обработки полилиний с packed-f64 ABI и 15 тестами, Web Worker, SVG/JSON, undo/redo, начальные фильтры и диагностика, скрипты Windows/Linux, CI и протокол REA/Ghidra.
- **Ограничения:** первоначально отсутствовали Rust/REA/Ghidra в среде и прямой доступ к Windows ArtCAM; поэтому в раннем журнале прямо отмечено отсутствие native/WASM/GUI-подтверждений. Позднейшие CI не должны задним числом превращать эти наблюдения в «изначально проверено».
- **Документ:** [архив handoff alpha.1](HANDOFF_ALPHA1_20261022_ARCHIVE.md).

## alpha.24–alpha.26 — большие EPS, цвет и корректный источник сохранения (23.10.2026)
- **alpha.24, PR [#30](https://github.com/tohaa28/relief-forge/pull/30):** drag-and-drop EPS, прогресс, пакетные вычисления при большом количестве узлов, частичная диагностика с честной маркировкой.
- **alpha.25, PR [#31](https://github.com/tohaa28/relief-forge/pull/31):** явный выбор EPS без цвета либо с исходной окраской. Нетронутый EPS выдаётся byte-for-byte, включая CMYK; после редактирования доступны простые solid RGB заливки/обводки, **без обещания восстановления ICC/CMYK**. Диагностические маркеры распределяются пространственно, а не берутся первые 1000 по обходу. Проверка положения маркеров привязывается к просчитанным контурам.
- **alpha.26, PR [#32](https://github.com/tohaa28/relief-forge/pull/32):** повторная диагностика результата ПОСЛЕ, в том числе пакетно; Save использует **готовый снимок ПОСЛЕ** и ранее полученные замечания без запуска лечения заново. Первоначальное объединение наложенных фигур стало составным объектом (не полноценный Boolean Union).
- **Метод:** когда есть пользовательское подтверждение остаточных ошибок — сохранять именно уже вылеченную геометрию, не оригинал и не новый скрытый перерасчёт.

## alpha.27–alpha.29 — настоящее объединение и контроль узлов (23.10.2026)
- **alpha.27, PR [#33](https://github.com/tohaa28/relief-forge/pull/33):** интеграция Clipper 6.4.2.2 (BSL) для реального Boolean Union **совместимых закрытых заливок одного цвета**, включая несколько \`M…Z\` внутри одного исходного CorelDRAW-объекта; сохранение отверстий, \`evenodd\`; полигонализация Безье с контролируемым допуском. Не выполнять Boolean для разноцветных объектов, открытых линий, неизвестных сложных эффектов.
- **alpha.28, PR [#34](https://github.com/tohaa28/relief-forge/pull/34):** чистка дублей, коллинеарных узлов и безопасных коротких сегментов после Union. Защита числом отверстий/компонент и симметрической разницей площадей; при отказе вернуть исходный корректный Union, а не испорченный силуэт.
- **alpha.29, PR [#35](https://github.com/tohaa28/relief-forge/pull/35):** выяснено, что прежняя оптимизация **до Union** уничтожалась при построении полигональных \`L\`. Добавлен post-Union refit в реальные \`M/L/C/Q\` с учётом допуска; «Узлы кривой» из режима ПОСЛЕ должны работать с результатом, а не сбрасывать на исходные кривые; Undo сохраняется.
- **Проверка:** реальные числа управляющих узлов до/после; после Union не выдавать тысячи рёбер полилинии за исходные точки Безье.

## alpha.30–alpha.33 — PDF и надёжность импорта на разных ПК (23.10.2026)
- **alpha.30, PR [#36](https://github.com/tohaa28/relief-forge/pull/36):** прямой MuPDF 1.28.1 WASM импорт PDF в SVG без растеризации всей страницы. Для многостраничного PDF выбирается одна страница; текст переводится в контуры, растровые вложения остаются растром, 64 МБ/500 страниц; экспорт остаётся EPS. Маскот скрывается независимо от поздних CSS.
- **alpha.31, PR [#37](https://github.com/tohaa28/relief-forge/pull/37):** SVG workspace health: фактический размер, CSS/display, \`viewBox\`, геометрия вне экрана, overlay, ручная диагностика и резервный контурный режим, автономный startup watchdog. Это диагностика, а не гарантия корректного GPU во всех ОС.
- **alpha.32, PR [#38](https://github.com/tohaa28/relief-forge/pull/38):** получен диагностический JSON \`8049569_10_29.10.eps\`: \`documentPaths=0\`, \`elementCount=0\`, холст 989×786 виден, \`mascotHidden=true\`, но \`ok=true\`. Введено различие между действительно пустым PDF и **ошибочным EPS с нулём импортированных объектов**; не заменять открытый документ при неудачном EPS; возвращать причину \`EPS_EMPTY_GEOMETRY\`.
- **alpha.33, PR [#39](https://github.com/tohaa28/relief-forge/pull/39):** после получения оригинала \`8049569_10_29.10.eps\` локально подтверждено: CorelDRAW 2020, 53 закрытых контура, 654 кубических кривых (651 \`C\`, 3 \`c\`), 58 \`L\`, Ghostscript визуально даёт пустую страницу, потому что это непечатаемые paths перед \`N/newpath\`. Резервный parser принимал \`C\` и отвергал \`c\` — исправлено на \`[Cc]\` без добавления искусственных узлов; исправлен устаревший \`corel-outline.js?v=alpha.18\` cache-buster; синтетические тесты без публикации частного EPS. [PR CI](https://github.com/tohaa28/relief-forge/actions/runs/39947972199), [main+Pages CI](https://github.com/tohaa28/relief-forge/actions/runs/39948169551) — успешны.
- **Текущая граница уверенности:** локальная независимая SVG-реконструкция настоящего файла и CI прошли; **на том самом проблемном Windows-ПК импорт alpha.33 пользователь пока отдельно не подтвердил**.
