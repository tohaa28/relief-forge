# Alpha.56 — отложенное локальное редактирование составной кривой

Дата: 2026-11-19. Ветка: `feature/alpha56-deferred-local-vector-editor`, PR [#86](https://github.com/tohaa28/relief-forge/pull/86).
Базовая проверенная версия: `0.2.0-alpha.55`, main после PR #85, контрольный SHA `cbf5495fa9af24677783bf0c86ffa46b6a12d49b`. Точка отката для кода alpha.55 `29b8efc9f879d9a7c04e2e51f4adf8199b507fb0`.

## Запрос пользователя
> Даже alpha.55 заметно тормозит: редактор должен изменять только локальные участки, а составную фигуру — пересобрать один раз после нажатия «Готово» или при переходе из режима редактирования.

## Результаты анализа alpha.55
Предыдущая alpha.55 уже рисовала в pointermove максимум два смежных сегмента и ограничивала количество видимых узлов до 240. **Однако в каждом pointerup** она вызывала `moveCurveNode`/`moveCurveHandle` на всём составном контуре (7545 C в примере `gerb2.pdf`), повторно сериализовала и парсила SVG artwork, делала JSON.stringify всего `doc` для сравнения, копировала историю (checkpoint), запускала локальную диагностику с `nativeParts` целиком и вызывала общий `render()` на огромной сцене. Даже при медленном движении между отдельными узлами это давало длинные фризы.

Отдельно: старый поиск ближайшего сегмента при ручном добавлении точки/right-click исследовал все 7545 C; снимок локального Undo перебирал массив всех узлов и копировал полный словарь типов. Первая версия новой транзакции ещё перерисовывала весь накопленный список локальных SVG-патчей при каждом выделении. Всё это исправлялось отдельными последующими коммитами.

## Архитектура alpha.56

### Вход в локальный редактор
- `createDeferredCurveEditor(doc.paths[path])` один раз копирует нативные команды и типы узлов в **локальную транзакцию** (команда M/L/Q/C/Z, без растризации). Исходный `doc.paths[path]`, EPS/PDF исходник, `artwork`, оформление, трансформации, ДО и общий Undo пока не меняются.
- Создаются spatial hash опорных узлов (не более 200 близких на экране) и отдельный spatial hash контрольных hull-границ сегментов для локального поиска при добавлении/правом клике. Поиск в обычном масштабе обращается только к близким корзинам; большие или экстремально вытянутые Bézier-контуры вносятся в общий список, чтобы не терять геометрию.
- HTML/SVG: `#geometry` содержит исходную фигуру и **не перестраивается** при локальных действиях. `#manual-patches` содержит только изменённые 1–3 реальных сегмента, `#manual-glyphs` — выбранные узлы и ручки. Два слоя живут независимо от исходной геометрии.

### Редактирование
- Pointermove: как в alpha.55, одно `path.setAttribute(d,...)` для локального превью, сгруппировано через requestAnimationFrame; никаких полных пересчётов.
- **Pointerup: нет `moveCurveNode`, `doc`-копии, JSON.stringify документа, перезаписи всего SVG, рабочего WASM, диагностики и общего `render()`.** Координаты применяются лишь к 1–3 командам транзакции и их индексным записям. Снимки Undo хранят 1–3 изменённых команды, прежние координаты и типы затронутых узлов, без обхода остальных 7545.
- Накопленные `manual-staged-segment` SVG элементы остаются на своих местах между кликами; обновляются только реально изменённые сегменты. Если элемент вернулся к исходным командам, его накладка удаляется. Это исключает непрерывно растущую стоимость перерисовки при десятках ручных исправлений.
- Добавление узла (de Casteljau), удаление, типы smooth/symmetric/cusp, линия/кривая, закрытие/размыкание и обратное направление работают на локальном command buffer. Сложные структурные правки могут одноразово переиндексировать затронутую составную кривую: это не делается на каждом mouseup с перемещением узла.
- Замыкание открытого контура показывает временное звено `Z` в локальном слое, без записи в оригинал.
- Внутри режима Ctrl+Z/Ctrl+Y используют **локальные** команды, не запускают полную диагностику и не меняют глобальную историю. Маркеры ранее обнаруженных проблем остаются видимыми, но **не считаются исправленными до выхода**.

### Выход из редактора
- По «Готово» (также перед экспортом, сохранением, открытием файла или сменой инструмента) только изменённые paths сериализуются `finishDeferredCurveCommands` через прежний проверенный writer, который сохраняет исходный SVG paint/transform/clip. Если сериализация не удаётся — **исходный документ не меняется**, режим остаётся открытым, сообщение об ошибке отображается.
- Делается **один** общий Undo-checkpoint перед атомарной записью обновлённых paths; после выхода вызывается одна полная диагностика и обновление режима ПОСЛЕ. Таким образом UI видит одну итоговую операцию, а не множество отдельных undo-слоёв.
- В режиме редактирования zoom/fit, видимость маркеров, изменение настроек и viewport resize обновляют только локальные слои. Общий clearance Worker остаётся остановленным до выхода.

## Проверки и ограничения
1. `tests/alpha56-deferred-local-editor.test.mjs`: 7545 C, 120 локальных перемещений подряд, оригинал строго неизменен, одна итоговая геометрия; местный Undo/Redo; криволинейные ручки, вставка/удаление узлов, явное Z, коррекция типов, spatial hash и откат.
2. `scripts/browser-alpha55-heavy-edit.mjs` (встроенный обновлённый тест alpha.56): реальный Chromium + WASM, составная фигура 2300 C; 40 mousemove, **семь** pointerup с неизменным `#geometry`, только 1–3 patched segments, местные Ctrl+Z/Ctrl+Y, один общий SVG-rebuild после «Готово».
3. `scripts/browser-manual-node-issues.mjs`: кольца проблем неизменны внутри редактора до «Готово», после полной диагностики исправленный разрыв исчезает, глобальный Ctrl+Z возвращает проблему.
4. Дополнительно обязательны все прежние EPS, PDF, Union, CNC, startup, реальные WASM и сохранение/экспорт.
5. Всё ещё O(N) единожды **при первом входе** в редактор на составную фигуру, при некоторых структурных топологических изменениях и **после выхода** при единой SVG сериализации. Основной цикл pointermove+pointerup перемещения узлов стал локальным. Работа с огромным числом одновременно затронутых сегментов и сложных групп SVG требует самостоятельного приёмочного прогона.
6. Исходный `gerb2.pdf` в публичный репозиторий не добавляется; синтетические нагрузочные тесты не заменяют прямое пользовательское тестирование.

Исправлено: аварийный сценарий запускается в независимом cold context с блокировкой Service Worker, перехватом `gs-core.wasm*`, проверкой факта HTTP 503 и диагностикой тайм-аута.
