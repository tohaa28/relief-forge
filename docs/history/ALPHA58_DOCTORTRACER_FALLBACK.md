# Alpha.58 — DoctorTracer: резервная растровая реконструкция при >10 неустранимых ошибках
2026-11-19. Рабочая ветка `feature/alpha58-doctortracer-fallback`, база main alpha.57 `9449e4d409ba8ec339d8fb066100d30e0ca18283`. **PR/CI ещё не подтверждены. Не утверждать, что это опубликовано.**
## Запрос
При более чем 10 **оставшихся после автоисправления** ошибках запускать DoctorTracer, сначала растрировать исходную импортированную векторную геометрию, затем пересоздать векторную структуру трассировкой, с минимальной потерей формы. Применять только полностью диагностированный результат; сохранять Undo/исходные кривые.
## Внешний проект
`tohaa28/DoctorTracer` отдельно от `relief-forge`. GitHub Pages `https://tohaa28.github.io/DoctorTracer/` использует проверенный тег `v0.16.0-wasm-preview` через `.github/workflows/pages.yml`; не текущий отстающий DoctorTracer main. Этот выпуск поддерживает модульный `/DoctorTracer/worker.js`, `operation:trace` (по умолчанию), вход `pixels:ArrayBuffer,width,height,category:'hard',colors:2,detail:2,speckle:0,polygon:false,gpu:false`, ответы `progress/stage`, `svg` или `error`. Сам Worker использует Rust WASM / Potrace. Код GPL DoctorTracer **не копируется в MIT relief-forge**, а вызывается как отдельный локальный same-origin Worker на GitHub Pages. На localhost этот Worker отсутствует без правильного маршрута — функция безопасно отказывает с ссылкой на DoctorTracer. Никакие клиентские данные не загружаются на сервер.
## Исполняемая последовательность
1. `checkPreviewAfter` после `diagnoseAfterDocument` и `runNativeJob('diagnose')`. Строго `issues.length>10`, `complete`, `fullScope`, весь вектор выделен, одна попытка на превью.
2. `rasterPlan(preview.source)` берёт **исходные импортированные команды**, не изменённый AFTER; вычисляет mm-ROI по исходной геометрии с полем 0.5 мм; ограничивает 300 DPI, 2400 px по длинной стороне, <=8M пикселей. Рендерит исходные закрытые пути чёрным силуэтом, открытые — чёрным штрихом толщиной 1 пиксель. Это адаптация для непечатаемых CAD/CAM EPS. Растры, недопустимые/вырожденные пути отклоняются без изменения документа.
3. `rasterizeDocument` создаёт SVG Blob + Canvas RGBA в браузере. Worker DoctorTracer `hard/2 colors/high detail` пересоздаёт SVG. `remapDoctorTracerSvg` импортирует его в mm, переносит в исходную ROI, сохраняет размеры страницы и имя файла, но удаляет старые EPS/PDF двоичные метаданные, которые не соответствуют новой геометрии.
4. Для независимой сверки новые геометрические контуры снова растрируются с тем же ROI/разрешением; бинарный силуэт должен совпадать с исходным по **IoU ≥0.95** и соотношению площадей в **[0.95,1.05]**. После повторной Rust+native диагностики кандидат принимается только если проверка полная и новых остаточных ошибок **строго меньше**, чем до трассировки.
5. Только после этого `preview.result` и `comparisonData.afterDoc` получают новый вектор. Сохранение/экспорт обрабатывают именно проверенную структуру. При `Применить изменения` общий `checkpoint` сохраняет оригинал для Undo; ДО не уничтожается. Worker abort/cancel/timeout, несходство силуэтов, ошибка импорта, неудовлетворительная диагностика = fail closed с сообщением и исходным AFTER.
## Ограничения и причины отказа
- Это **намеренная растровая аппроксимация**, не тождественное восстановление исходных Bézier или единственной центральной линии. Для гравировки/ЧПУ она может превратить открытую осевую линию в замкнутый контур обводки; проверять глазами перед выводом.
- Не запускать если диагностика частичная, отобрана лишь часть объектов, присутствуют растры или внешнее ядро недоступно. Worker работает только при origin `tohaa28.github.io` и штатном deployment DoctorTracer.
- Ни одно улучшение счётчика дефектов не оправдывает полное изменение формы; форма проверяется отдельно. Возможно пропускать слишком тонкие линии / сложные рисунки, что честно отображается в UI.
- Порог **>10**, не ≥10. Не перепроверять снова трассированный документ, чтобы не зациклиться.
