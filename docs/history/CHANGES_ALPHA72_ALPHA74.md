# Доктор Узелков: внесённые изменения alpha.72–alpha.74

Сводка текущей серии работ по обработке импортированного вектора, редактору и сглаживанию. Все три релиза уже объединены в main и опубликованы. Документ составлен до начала новой оптимизации зума в режиме просмотра.

## 1. Новый порядок обработки изображения — alpha.72

1. Исходный вектор сохраняется как неизменяемое **ДО**.
2. Создаётся независимая рабочая копия. Совместимые части объединяются в один объект; геометрическое Union применяется там, где это допустимо с учётом заливки, обводки и отверстий. Небезопасные/разные стили не объединяются безусловно.
3. Диагностика ищет дефекты на подготовленной копии. Добавлен промежуточный просмотр **ОБЪЕДИНЕНО · ДЕФЕКТЫ**.
4. Исправления формируют **ПОСЛЕ**. Обычный и большой документы проходят один порядок стадий.
5. Для сравнения весь исходный вектор показывается контурной подложкой под ПОСЛЕ, в том числе после изменения количества объектов при объединении.

Apply, Undo и EPS используют реальную геометрию результата. Открытие редактора не теряет исходную историю. [PR №104](https://github.com/tohaa28/relief-forge/pull/104) · [Детальная история](ALPHA72_UNION_DIAGNOSE_REPAIR.md).

## 2. Производительность зума редактора кривых — alpha.73

- Последовательность wheel-событий накапливает точную камеру относительно курсора; SVG получает одно обновление на animation frame.
- Зум не пересоздаёт полный DOM исходного вектора и не меняет команды кривых.
- Добавлены кеш границ сегментов, ограниченный выбор ближайших сегментов, ленивая сериализация SVG и локальная инвалидация кеша при правке/Undo.
- Локальный viewport учитывает управляющие точки и смещения объектов; при увеличении ограниченный кеш своевременно обновляется.

Измерение в Chromium на синтетических20 000 кубических сегментах при CPU4×: серия60 wheel — около294→5.4мс, одна запись viewBox. Это измерение обработки серии событий, не пользовательского FPS или GPU. [PR №105](https://github.com/tohaa28/relief-forge/pull/105) · [Методика и измерения](ALPHA73_EDITOR_ZOOM_SMOOTHING.md).

## 3. Исправление сглаживания смещённых объектов — alpha.73

Проверка качества ошибочно сравнивала локальные координаты источника с мировыми координатами результата. Исправлено единое сравнение мировой геометрии: сглаживание смещённого объекта допускается при сохранённых мировых опорных точках; произвольный перенос через offset не принимается как unchanged. Проверены реальные ручки, уменьшение угла стыка, EPS, Undo/Redo и151 стык большого документа. Геометрические ограничения не отключены.

## 4. Скругление острых углов Безье — alpha.74

- По уточнению пользователя сглаживание теперь скругляет острые стыки прямых и кривых L/Q/C, включая замыкающий угол.
- Исходные участки точно подрезаются de Casteljau; между ними вставляются реальные кубические C с согласованными касательными.
- Параметр в мм ограничивает изменение формы: большее значение даёт более заметное скругление,0 отключает. Это допуск, не фиксированный радиус.
- Скругление выполняется последним этапом в Worker после очистки близких узлов, чтобы очистка не удаляла дуги.
- Допустимое добавление узлов учитывается отдельно. Общие ограничения оптимизатора и защита исходного ДО сохранены.
- Проверяются свободные концы, замыкание, части, ориентация колец и новые пересечения. При неопределённости этап откатывается с причиной.
