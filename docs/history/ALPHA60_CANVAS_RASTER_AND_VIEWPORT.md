# Alpha.60: корневая причина и исправление (2026-11-19)
## 0.2.0-alpha.60 — правильный Canvas2D→DoctorTracer 0.21.1 и локальный SVG zoom (2026-11-19)
- **Статус: кандидат** в ветке `feature/alpha60-canvas-raster-local-viewport`; не утверждать публикацию до успешных JS/Rust/WASM + реального Chromium smoke CI и деплоя. Rollback alpha.59: `345fac5b7df66120fdaa84284c2a5985b9d497ad`.
- Источник фактического сбоя: пользовательский `relief-forge-session.jsonl` alpha.59. EPS 1 226 967 B, 1 975 импортированных векторов, 22 219 узлов, 61 084 диагностических sampled points, 1 115 проблем на ДО, 398 на ПОСЛЕ. `doctortracer-fallback-start` в 08:50:22.194Z; спустя **75 мс** `doctortracer-fallback-rejected`: `The source image could not be decoded.`. **Worker не получил сообщение:** исключение из `createImageBitmap(Blob(giantSVG))` в `rasterizeDocument`, а не неверный формат Worker. Подтверждённый Worker `tohaa28/DoctorTracer` `gh-pages` 0.21.1 ожидает `{pixels:ArrayBuffer,width,height,category:'hard',colors:2,detail:2,...}`. Библиотека GPL не копируется.
- Исправление: удалён SVG blob / `createImageBitmap` из рабочего пути. Прямой `CanvasRenderingContext2D` + `Path2D` для исходных **M/L/Q/C/Z** с геометрией в мм, сохранением evenodd отверстий и тонкими линиями для открытых подконтуров; RGBA `Uint8Array` передаётся transferable Worker (пакеты по 48 исходных объектов, `await yieldForUi`, AbortSignal, прогресс). Сравнение исходного/нового растрового силуэта и полная native диагностика после Worker оставлены строгими. В `record` удалён дублированный `stats.budget.document` (одна реальная запись была **11.35MB** вместо компактной статистики) и добавлены `doctortracer-raster-ready`, `doctortracer-worker-result`. Любое отклонение = исходник без изменений.
- Ручной zoom: вместо `display:none` только **ПОСЛЕ изменения viewBox** теперь исходные 1975 SVG-объектов паркуются в `DocumentFragment` **ДО** первого wheel/pan/focus. `buildManualViewportIndex` строит индекс всех исходных кривых один раз на входе, запрос затрагивает только видимую область (не только выбранный объект); до 420 сегментов общих + 180 текущего редактора на глубоком зуме, после `fit` исходная сцена возвращается. События колеса коалесцируются в 1 requestAnimationFrame; сохранены 12px hit-контуры и исходный Untouched/Undo.
- Тесты: `tests/doctortracer-fallback.test.mjs` добавляет Canvas mock, 1975-path batches, compound holes/open Q/C; `tests/alpha60-viewport-index.test.mjs` 1975 paths + bounding/culling, оригинал immutable; `scripts/alpha60-browser-smoke.mjs` запускает **настоящий headless Chromium** (не mock Canvas2D) и проверяет 1975×11 Bezier raster, неподверженность `createImageBitmap`, evenodd отверстия, 160 indexed zoom queries. `.github/workflows/pages.yml` добавляет эту проверку.
- Ограничения: исходное изображение в растре только **чёрно-белый силуэт**; возможна смена открытой центральной линии на замкнутые внешние обводки, мелкие элементы при 2400px по стороне могут потеряться. Самостоятельное принятие результата только если полная re-diagnose, issue reduction, IoU≥.95 и площадь 95–105%. Реальный пользовательский EPS и реальный DoctorTracer Worker в браузере **не протестированы end-to-end** (имеется только диагностический JSONL, нет байтов EPS).
- Полная история, методы, проверки: `docs/history/ALPHA60_CANVAS_RASTER_AND_VIEWPORT.md`. Перед дальнейшей работой сверять CI, PR, release и `docs/history/FAILURE_REGISTER.md`.

## Точный анализ пользовательского JSONL
Первая диагностика: 36 партий, 61 084 sampled points, 1 115 замечаний, complete=false при 0 пропущенных объектах (native unresolved=5). Предпросмотр после автоисправления: 1 975 путей, первоначально 22 219 настоящих узлов → 21 271 в AFTER, 398 замечаний, complete=false, fullScope=true. Пользовательская гипотеза о неверном формате передачи DoctorTracer оказалась неполной: **передача не состоялась**, т.к. `rasterizeDocument` вызвал `createImageBitmap` на гигантской строке SVG, и декодер вернул `The source image could not be decoded.`. Восстановление было вызвано, поэтому условие >10 и видимость статуса alpha.59 уже работали.
## Почему прежний ручной zoom продолжал зависать
Alpha.59 делала `display:none` для `#geometry` в `refreshLocalZoomGeometry` только ПОСЛЕ `$('canvas').setAttribute('viewBox')`, часто в следующем rAF. Браузер уже инициировал paint / recalculation всех 1 975 сложных SVG объектов. Дополнительно код выбирал лишь одну `manualFocus.path` и при отсутствии её кривых возвращал полный SVG без изоляции; это давало катастрофические откаты производительности при panning. Новый алгоритм до изменения `viewBox` полностью отделяет исходную геометрию от SVG root во fragment; общая native структура кривых создаётся один раз, каждый viewport выбирает только локальные сегменты, независимо от выбранной кривой. На Fit возвращает исходный DOM, на выходе код `render()` восстанавливает его из исходника.
## Растеризация: обязательная технологическая цепочка
`rasterPlan` вычисляет исходную область в миллиметрах (max 2400px сторона / 8Mpx всего). `makeRasterPaths` делит M...Z на замкнутые и открытые части, не смешивая отверстия внутри одного compound. `CanvasRenderingContext2D` с геометрическим `setTransform` отображает исходные кубические/квадратичные сегменты прямо в RGBA без SVG Blob, DOMParser, ImageBitmap, шрифтов и внешних изображений. Заливка evenodd для compound; незамкнутые линии stroke 1px. Пакеты 48 объектов с немедленным сигналом отмены/прогрессом. Отбрасывается полностью прозрачный растр. Результат получает Worker 0.21.1 через `postMessage({pixels:Uint8Array.buffer,width,height,category:'hard',colors:2,detail:2,speckle:0,polygon:false,gpu:false},[buffer])`. Цветность исходного EPS не сохраняется: этот fallback специально монохромный, не использовать для полутоновых оригиналов без согласования.
## Производительность/журнал
Новый `manual-viewport-index.js`: контрольные многоугольники C/Q консервативно проиндексированы по spatial bins; запрос не клонирует документ, не обходит весь массив, не строит DOM на каждой итерации. При >12000 ячеек предусмотрен безопасный отказ от недопустимого перебора пустых клеток. SVG d формируется один раз при индексировании, текущий `Map(path → hit,visual)` держит только локальную геометрию и обновляет `d` при фактическом изменении выборки. Статус редактора, исходные узлы, импортированная геометрия и Undo сохраняются. Добавлен 1-frame wheel accumulator. 
Журнал `large-preview.stats.budget.document` из реальной сессии содержал 11 350 812 байт JSON вложенного оригинала и увеличивал файл сессии до 11.2 MB. В alpha.60 рекордер отделяет `budget.document` и большую `scope` от event detail, оставляет `budget.reason,before,optimized,after,final` и `scopeCount` без потери диагностических чисел.
## Не повторять
- Не требовать полного Rust полного диагностика для запуска Worker: для запуска достаточно >10 подтверждённых проблем; полная нужна только для приёма новой геометрии.
- Не направлять гигантский SVG в `createImageBitmap`: ошибка браузера подтверждена журналом.
- Не менять viewBox, пока полная сложная SVG сцена ещё в root; прежнее `display:none` после rAF слишком поздно.
- Не ограничивать прорисовку одной кривой, если дизайнер перемещается на другую — это возвращает полный исходный SVG и вызывает замедление.
- Не записывать `stats.budget.document` в журнал; 11.35 МБ в одной записи — регрессия памяти.
- Не утверждать измерение FPS на исходном EPS: его байты в текущем чате отсутствуют.
