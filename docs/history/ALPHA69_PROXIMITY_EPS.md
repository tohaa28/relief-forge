При 0.05 мм 658 коротких native-control-hull сегментов (448 L + 210 C), при 0.025 мм — 574, при 0.01 мм — 507. 573 пары точек разных объектов ближе 0.05 мм; 2116 пар НЕсоседних точек в пределах одного замкнутого подконтура после исключения законного шва M/end. ## Алгоритм и запреты
1. Для выбранного path составить цепи оригинальных M/L/Q/C/Z, вычислить расстояние/контрольный hull в миллиметрах, а не только между концами сегмента. Опциональный допуск 0.0001–1.0 мм, начальный 0.05 мм.
2. Если два соседних узла разделены сегментом, весь контролируемый hull которого <= толеранса, построить кандидата: удалить только этот сегмент, конечную точку предыдущего поставить в точку конца удаляемого, сдвинуть ближайшую C/Q ручку на величину перемещения. Не удалять последние сегменты замкнутых колец или отклонять подозрительный U-поворот.
3. Независимая геометрическая защита: аналитическая подписанная площадь каждого кольца через точное 3-точечное Гауссово интегрирование кубики, отсутствие смены ориентации, локальное сравнение точных crossing/overlap свидетелей до и после, включая соседние объекты в пространственном индексе. Превышение бюджета = пропуск, не успех.
4. Near-duplicate contours: только независимые полные closed-команды одной структуры с каждой командной координатой в пределах допуска и совместимой полностью непрозрачной paint; нельзя удалять пары с разной заливкой, масками, прозрачностью и трансформациями.
5. Open-end welding: только точно один близкий уникальный партнер, незалитые кривые одинакового stroke/offset, согласованная касательная. Присоединять оригинальные Bézier commands без полилинейной аппроксимации; не соединять независимые заполненные фигуры через зазор.
6. Исходные данные не менять до «Применить изменения». При ошибке/неполной проверке — исходный путь в AFTER, статистика skipped/limited, полноценный Undo. Выход из режима ручных узлов не выполняет полного пересканирования.

## Производительность
При импорте массив из ~1975 объектов и ~20k сегментов. Для локальной проверки хранить индекс world-space контрольных hull, переиндексировать только изменённый объект, ограничивать maxLocal=104 и количество исправлений. Кандидатные объекты могут содержать множество под-контуров; нельзя запускать глобальный анализ всех 20k сегментов при каждом движении мыши.

## Тесты/публикация
Синтетические unit tests доступны в tests/nearby-curve-merge.test.mjs. Команды, цвета, экспорт EPS, отказ от ложной очистки колец/разных цветов, selection-only, staging и отсутствие повторной диагностики после manual Done проверять CI. Не передавать пользовательский EPS в публичный GitHub и не заявлять успешную починку большей части реальных ошибок без фактической разметки/полного приложения.

## Незакрытые вопросы
- Полная проверка EPS внутри браузерного приложения на реальных исходных байтах в доступном контексте ещё не выполнена. Доступен только внешний независимый разбор PS-команд и Ghostscript preview.
- Вырожденные петли и пересечения, где безопасная сварка не доказана, должны оставаться без изменений. Пользовательскому дизайнеру нужна прозрачная индикация числа пропущенных кандидатов.
