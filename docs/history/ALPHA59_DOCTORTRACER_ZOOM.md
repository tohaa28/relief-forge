# 0.2.0-alpha.59 — DoctorTracer 0.21.1 + ускорение увеличения ручных узлов
Дата: 2026-11-19. Feature branch `feature/alpha59-doctortracer-trigger-manual-zoom`. PR: https://github.com/tohaa28/relief-forge/pull/90. Исходное безопасное состояние main alpha.58: `a29802f59dafbde80fd28c18feb64db562f8a0ec`. **До финального main CI + deploy не утверждать публикацию.**
## Поступившие замечания
1. На самом сложном импортированном EPS/PDF не происходило перехода на DoctorTracer. 2. Реально размещённая версия DoctorTracer WASM 0.21.1, а не использовавшаяся в ссылках и статусах 0.16.0. 3. При увеличении рядом с узлом ручной редактор резко тормозит.
## Доказанная причина 1: неподходящий критерий запуска
В alpha.58 `needsDoctorTracer` требовал одновременно `report.complete===true && report.fullScope===true` и `report.issues.length>10`. Для тяжёлых файлов `diagnoseAfterDocument` маркирует проверку `partial`, потому что ограничены сканируемые блоки, возникают пропуски/межблочные связи. **Но >=11 подтверждённых ошибок — уже достаточная нижняя граница N, независимо от полноты других участков**. Поэтому предыдущий обработчик просто молча возвращал `report` и не запускал трассировку. В alpha.59 условие исправлено: если больше десяти фактически найденных неисправленных замечаний, полный вектор выбран в области обработки и попытки ещё не было, трассировку запускать даже при частичной проверке. Важное отличие: **приёмка результата трассировки по-прежнему требует полной нативной и Rust диагностики** нового SVG, подтверждённого уменьшения числа дефектов, IoU >=0.95 и сохранения площади 95–105%. Не подменять неполную проверку гарантией чистоты, не переписывать исходник при неудаче.
Состояния выводятся в `#doctortracer-status`: недостигнут порог, выбрана не вся геометрия, "DoctorTracer 0.21.1 WASM запущен", принята либо отклонена новая структура; исходный документ сохраняется при ошибках. Таймаут Worker 240 секунд (вместо 120) для тяжёлых файлов с отменой. Независимый Worker загружается по `/DoctorTracer/worker.js?v=0.21.1`, cache-bust.

`tohaa28/DoctorTracer` default `main` содержит старую версию и старый workflow `.github/workflows/pages.yml` pinned v0.16.0-wasm-preview. **Реальная опубликованная `gh-pages`**: commit `48dfa7b6ea268df1b45bc6ea22981eaba1ee9026` с заголовком `Publish web navigation fix 0.21.1` (2026-11-10), `index.html` загружает CSS/JS `?v=0.21.1`, footer `DoctorTracer 0.21.1 · Desktop WASM`, `worker.js` импортирует `rust-tracer.mjs?v=0.21.1`, `gpu.js`, `gpu-contours.mjs`, `desktop-curves.mjs`. ## Причина 3: HTML/SVG repaint и постоянная пересборка маркеров
До alpha.59 `zoom()` после каждого `wheel` вызывал `drawLocalEditorOverlay()`, который делал `#manual-glyphs.replaceChildren()` и заново создавал до 200 SVG-квадратов/кружков, а браузер пересчитывал **весь** сложный 7.5k-C compound SVG в `#geometry` при каждом изменении `viewBox`. При drag уже была локальная транзакция, но zoom оставался дорогим.
Новый алгоритм: `scheduleManualZoomRefresh` с одним `requestAnimationFrame` на кадр; между крупными изменениями масштаба (менее 1.8×) существующие маркеры масштабируются **in place**, без `replaceChildren`; обычный реиндекс и перерисовка малой пачки только при значительном изменении размера. `createDeferredCurveEditor.visibleSegmentSVG(center,radius,{limit:600})` использует уже имеющийся spatial-bin native Bézier индекс и отдаёт только исходные или локально исправленные сегменты C/Q/L из прямоугольника viewport; SVG слой `#manual-local-geometry` содержит до 600 отдельных subpaths, а общий `#geometry` скрыт через CSS `display:none` **только при** ручном режиме, более 1800 команд и увеличении до меньше 35% исходного документа по обеим осям. Это устранит повторный paint всей сложной фигуры. При выходе/уменьшении вся исходная SVG-картинка восстанавливается без пересборки исходника; первоначальный источник и Undo нетронуты.
`manual-live-patch` перенесён из `#geometry` в видимый независимый `#manual-patches`, чтобы drag-подсветка не скрывалась вместе с тяжёлым базовым SVG. Поворот/пан/зум обновляют только локальный экранный слой. Кривые в локальном слое являются геометрическими, а не точечной растровой моделью.
**Компромисс:** на глубоком зуме, когда активирован локальный режим, на экране показывается только текущая редактируемая фигура и ближайшие до 600 сегментов; остальные объекты скрыты ради производительности, но в документе/памяти остаются. При зуме обратно или выходе из редактирования все возвращаются. Просмотр точных заливок и цветных слоёв в этом режиме ограничен.

## Ограничения
Реконструкция возвращает заполненный силуэт; открытые осевые линии могут превратиться в обводочные замкнутые контуры. Мелкие детали могут потеряться при ограниченном dpi. Если Worker/трассировка/проверка качества отклонены, источник остаётся без изменений. Сохранён единый механизм «Применить изменения», не менять документ автоматически без проверки и возможности Undo.
