## Воспроизведение и измерения

`scripts/browser-alpha73-zoom-smoothing.mjs` создаёт одну синтетическую составную кривую: 40 рядов по 500 C-сегментов, всего 20 000 кубик. В viewport-бенчмарке тестовый hook открывает сырую геометрию без предварительного автоисправления, чтобы не измерять импорт/Union и не тестировать уже упрощённый результат. Hook добавляется только сетевым перехватом в тестовом браузере; production app его не содержит. Chromium, viewport 1440×980, CDP CPU throttling 4×, 60 синхронных wheel событий + 24 настоящих mouse.wheel; исходные команды и DOM проверяются отдельно.

| Измерение | Alpha.72 до правок | После правок (два локальных прогона) |
|---|---:|---:|
| Синхронная серия 60 wheel, мс | 294,0 | 5,3–6,1 |
| Сумма CPU обновления локальной геометрии, мс | 289,3 | 22,8–31,5 |
| p95 построения glyph/локального слоя, мс | 166,2 | 22,1–30,5 |
| p95 самого вызова zoom, мс | 0,2 | 0,2–0,3 |
| Реальных C в итоговом локальном слое | 600 | 164 |

Это измерения синтетической сцены с замедлением CPU, **не** обещание ускорения пользовательского GPU/файла в указанное число раз и не замер FPS. Снижение C в отображении связано с обновлением прежде чрезмерно большого/усечённого viewport-кеша, а не с удалением узлов: все 20 000 C остаются в исходнике. Отдельная проверка рассчитывает ожидаемую камеру для всех 60 событий и требует совпадения с точностью 1e-7. MutationObserver подтверждает ровно одну запись viewBox в серии.

## Корневые причины и изменения

1. `zoom()` менял viewBox на каждом wheel и при первом переходе к локальному слою синхронно обходил тяжёлую сцену. Теперь накапливается только виртуальный `manualPendingView`, включая все преобразования относительно курсора. Один RAF записывает итоговый viewBox, изолирует тяжёлую SVG и обновляет локальный слой до отрисовки кадра. При новом захвате узла используется реально отображённый viewport, скрытая отрисовка не переносит узел в процессе drag.
2. `visibleSegmentSVG()` реконструировал controls и строку SVG для **всех** кандидатов, сортировал их, затем выбрасывал всё кроме 600. Теперь используются закешированные world-space control hulls, bounded max-heap ближайших K и ленивая сериализация только выбранных сегментов. Повторный запрос не создаёт новые строки; move/handle/Undo обновляет лишь затронутые сегменты, структурные операции перестраивают индекс штатно.
3. Усечённый слой мог считаться пригодным для любого последующего увеличения, пока огромный запас покрывал viewport. Кеш теперь помнит span/limited: усечённая выборка обновляется при значительном зуме или сдвиге, а не держит 600 далёких фрагментов. Масштаб glyph обновляется относительно последней рескалибровки.
4. Границы соседних объектов прежде считались по локальным endpoints, без ручек и offset. `manualVectorBounds()` один раз строит консервативный hull в мировых координатах; дуга с дальними ручками и смещённый сосед не должны пропадать при culling.

## Подтверждённая ошибка сглаживания

Регрессионный вход — открытые C/C с якорями (0,0), (3,0), (6,0.5), второй outgoing handle (4,0.1), offset (10,20). В alpha.72 `smoothVectorPath(...,0.05)` возвращал `changed:0`, quality `new-or-moved-anchor`, хотя мировые опорные точки не двигались. Причина: результат smoothing записывает world commands с offset 0, а quality сравнивал их с локальными source anchors. Обратная ошибка: изменение только offset при одинаковых local commands считалось unchanged/accepted.

`curve-quality.js` теперь сравнивает world-space M/L/C/Q/Z через geometryCommands. В объединённой проверке и bounds повторное прибавление offset удалено; изображения не попадают в векторное сравнение. Допуски, ограничения пересечений, площадь, защита углов и исходный алгоритм сглаживания **не ослаблялись**.

До исправления новые два теста упали по указанным причинам; после исправления проходят. UI-проверка на обычной кривой с отключённой оптимизацией узлов (0.00001 мм) подтверждает: 0 мм сохраняет handles, 0.05 мм меняет реальные handles, якоря остаются на месте, рассогласование касательных 5.7106° → 3.8834°. Это уменьшение излома, не заявление точной G1-непрерывности. Проверены cached EPS по всем числам, Undo/Redo и large route на 151 исходной кривой / 302 C / 151 сглаженном стыке. Изменение полей остаётся staged до Apply.

- Локальный checkpoint: 420/420 JS PASS, отдельные browser alpha66 (2300 C), alpha56 (40 pointermoves / 7 mouseups без global rebuild), новая 20k viewport и smoothing UI / EPS / Undo / large PASS.
