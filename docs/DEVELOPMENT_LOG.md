- Добавлен режим показа всех реальных узлов кривых: нейтральные незалитые тонкие круги; дефекты цветом по типу. Ручки Безье не подменяют реальные узлы. Два независимых переключателя отображения.

## 2026-10-22 · 0.2.0-alpha.7 · компактный интерфейс / бесцветный EPS для старого ArtCAM

- Левая информационная панель `info-panel` скрыта при загрузке, сетка расширяет рабочую область; «Сведения» раскрывает/сворачивает панель без сброса документа. Инструменты создания нового документа помещены в закрытое по умолчанию `<details>`.
- EPS-экспорт переведён с рисующего `stroke`/цвета/`setlinewidth` на исключительно векторный PostScript (`m`, `L`, `C`, `@c`, терминальный `N`) с `%%Creator: Relief Forge` и маркером `%%RF-OutlinePaths: 1`. Преобразование кривых M/L/C/Q/Z сохраняет геометрию, цвет и печатаемая толщина не передаются даже из окрашенных входных EPS.
- Расширен восстановитель `corel-outline.js`: восстановление только доверенных CorelDRAW либо маркированных paintless Relief Forge EPS, корректная поддержка нескольких открытых путей, сохранение исходного размера.
- Векторные EPS без печатных операторов будут выглядеть пустыми в обычном Ghostscript/PDF просмотрщике по замыслу. Назначение — старый ArtCAM, который импортирует неотображаемую геометрию; совместимость с конкретной установленной старой версией ещё не проверена.
- Добавлены тесты: цветной источник → бесцветные пути, открытые и закрытые, кривая Q→C, повторный импорт, отсутствие PS paint-команд и состояние интерфейса по умолчанию. Выполнение CI, браузер и публикация отмечаются отдельно по факту.
