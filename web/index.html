Ограничения автоисправления

Автоисправление устраняет только однозначные совпадения и близкие концы. Для кривых Безье предлагается аппроксимированная копия с заданным допуском — исходный EPS сохраняется в истории. Самопересечения и сложные наложения остаются для ручного решения.

Оптимизация кривых Безье

Меньше допуск — точнее форма. Объединяются соседние сегменты Безье, только если ошибка ниже допуска. Исходник сохраняется в Undo.

Ручные действия с проблемами

Alpha: кривые Безье, дуги и булевы операции ещё не поддерживаются. Пересекающиеся коллинеарные участки только отмечаются. CNC и рельефы появятся на следующих этапах.
