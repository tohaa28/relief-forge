# Relief Forge — 0.2.0-alpha.11

Независимый Rust/WASM-редактор для подготовки векторов. Цель проекта — поэтапный функциональный аналог ArtCAM 2018. Приоритет: полный набор диагностики и лечения векторов. Текущая контрольная точка — **исходный прототип**, не готовая замена ArtCAM.

## Статус на 22 октября 2026

- Rust 1.85.1 установлен из официального источника в изолированный каталог; настоящий модуль `wasm32-unknown-unknown` собран.
- **15 Rust-тестов, 12 JavaScript-тестов и интеграционные проверки скомпилированного WASM проходят.**

- Полная эквивалентность ArtCAM не заявляется. REA/Ghidra-анализ пока не выполнен: Windows-процесс недоступен.

## Сборка и запуск

Требуются Rust + rustup и Node.js. У Rust-ядра пока нет внешних crate-зависимостей.

Windows: запустить `BUILD_WINDOWS.bat`. Либо:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build.ps1 -Serve
```

Linux/macOS:

```sh
bash scripts/build.sh
npm run serve
```

Открыть `http://localhost:8080`. Через `file://` Web Worker/WASM не запускается.

Сборка сначала проверяет Rust и JavaScript, затем создаёт `web/engine.wasm` и проверяет его настоящий ABI в Node.js. Логи сохраняются в `logs/`.

## Первая версия

Рабочее поле в мм; ломаная, прямоугольник, аппроксимация окружности 96 отрезками; редактирование узлов; сдвиг объектов; масштаб и панорама; выделение; undo/redo; сохранение JSON-проекта с геометрией, историей и журналом; SVG-экспорт.

Rust: поиск открытых контуров, совпадающих узлов, дубликатов с одинаковой сегментацией, самопересечений, пересечений разных объектов, коллинеарных наложений, коротких отрезков. Исправления отдельными командами: удаление дубликатов/последовательных близких узлов, соединение однозначных концов, замыкание близких концов, разворот, упрощение открытых полилиний, разбиение на отрезки, выделение простых самопересекающихся петель.

## Контурный EPS без заливки — 0.2.0-alpha.11

Если CorelDRAW EPS содержит только прямые/кубические контуры и заканчивается `N` (сброс пути без рисования), Ghostscript законно возвращает пустой лист. Для этого узкого варианта добавлено восстановление точной геометрии из буквальных `m/L/C/@c/N` команд страницы. Линии на экране получают видимую тонкую обводку, **не являющуюся заданной в макете толщиной печати**; исходные байты EPS остаются в проекте. 17 контуров файла `7921701_02_09.eps` обнаружены локальным проверочным алгоритмом. После восстановления запускается диагностика Rust автоматически. Неподдерживаемые PostScript-операторы внутри контуров не угадываются: для других форматов действует обычный Ghostscript/MuPDF.

## Компактный интерфейс и EPS для старого ArtCAM — 0.2.0-alpha.11

- Левая информационная панель закрыта при каждом запуске, открывается кнопкой «Сведения». Кнопки «Новый», «Ломаная», «Прямоугольник», «Окружность», «Пример» скрыты внутри «Создание документа» (закрыто по умолчанию). Редактирование, диагностика и экспорт остаются доступными.
- «Сохранить EPS (без цвета)» экспортирует только команды `m/L/C/@c/N` и метаданные EPSF-3.0, без `stroke`, `fill`, `setlinewidth` или цветовых операторов. Источник с видимыми цветными линиями точно так же экспортируется бесцветным. Точность кривых Безье сохраняется; растр и оформление с клиппингом явно отклоняются.
- **Такой EPS специально пустой в обычных PostScript/PDF-просмотрщиках**: они рисуют только объекты с операторами закраски. Для старого ArtCAM файл предназначен как набор невидимых печатно, но читаемых редактором путей. Автоматическая совместимость проверяется обратным импортом Relief Forge и Ghostscript; установка старого ArtCAM недоступна, реальная проверка в нём остаётся необходимой.
## Ограничения, которые нельзя потерять

- EPS/EPSF/EPSI (включая двоичный DOS-заголовок) интерпретируются Ghostscript WASM → векторный PDF → MuPDF WASM → SVG. Сохраняются кривые, составные контуры, обтравка, изображения, цвета/обводки, текст в контурах и размер в мм. Оригинальный EPS включается в проект. Необходимые внешние шрифты можно добавить перед импортом; предупреждения показываются явно.
- Импортированные кривые можно перемещать, удалять, сохранять и экспортировать в SVG. Точное редактирование ручек Безье ещё не реализовано. Для полилинейного лечения — «Копия для лечения» с заданным допуском; оригиналы сохраняются. Диагностика кривых использует временную аппроксимацию.
- Предел EPS 64 МиБ, шрифтов 32 МиБ; отмена и таймаут 120 с. Поддержка всех конкретных файлов ArtCAM/Illustrator/Corel не доказана. Отсутствующие шрифты могут заменяться интерпретатором; для точного результата загрузите исходные шрифты. Сложные заливки/шэйдинги могут стать локальными изображениями в SVG. Исходные редактируемые текстовые объекты, имена PS-процедур и структура оригинального файла не восстанавливаются.
- Нет ART/CDR/DXF/PDF-импорта, рельефов, траекторий, постпроцессоров и G-code.
- Пересечения ищутся за O(n²); лимит 2000 узлов за расчёт, 10000 замечаний. Неполнота диагностики явно сообщается. Расчёт в Worker можно отменить.
- Соединение неоднозначных узлов не угадывается. Коллинеарные наложения диагностируются, не лечатся автоматически.
- Выделение петель обрабатывает внутренние пересечения сегментов; касания/совпадения узлов и сложная топология ещё требуют отдельного алгоритма. Ограничение рекурсии 256.
- Процент площади петель пока считается от суммы модулей площадей выделенных циклов. Это **не подтверждённая эквивалентность** ArtCAM.
- Упрощение закрытых контуров пока не выполняется. Для открытых действует геометрический допуск, без гарантии сохранения топологии.
- Отдельные слои, группы и вывод исправлений на новый слой ещё не реализованы. Исходники сохраняются историей undo и файлом проекта.

## GitHub — основной источник и публикация

Репозиторий: https://github.com/tohaa28/relief-forge

GitHub Actions собирает Rust/WASM, выполняет 15 Rust-тестов, 12 JS-тестов и проверки модуля, затем публикует `web/` в GitHub Pages. Pages Source должен быть GitHub Actions. Опубликованная и проверенная версия: https://tohaa28.github.io/relief-forge/

Полная исходная история сохранена в `history/pre-github.bundle`; первый workflow включает её точные коммиты в граф основной ветки. Готовый проверенный WASM и протокол проверок сохранены также в `releases/0.1.0-alpha.2/`.

Sites больше не является основным маршрутом разработки. Его прежняя привязка архивирована в `docs/legacy-sites-hosting.json`. Продолжать работу в этом GitHub-репозитории.
